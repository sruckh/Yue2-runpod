# This file is copied into the repository rather than fetched during the image
# build. Two reasons:
#
#   1. Reproducibility. Fetching a URL at build time means the image depends on
#      whatever that URL serves today, so a rebuild can silently produce a
#      different image. Vendoring pins it.
#   2. It documents the constraint that drives the base image choice.
#
# **The numpy pin is why SheetSage2 needs Python 3.11, and it is not
# negotiable by accident.** numpy 1.24.3 (April 2023) predates Python 3.12
# (October 2023) and publishes wheels for cp38–cp311 only. On 3.12 pip finds no
# wheel and tries to build numpy from source, which fails — 1.24 does not
# support 3.12. So this environment is 3.11, and the base image is
# `python:3.11-slim-trixie` rather than 3.12.
#
# torch and torchaudio are installed from the CUDA 12.6 index *before* this
# file is applied — see the Dockerfile. Installing them from PyPI here would
# pull CPU-only builds. The pins below are then already satisfied and skipped.
# (`==2.8.0` matches `2.8.0+cu126`: a local version identifier is ignored when
# the requirement does not specify one.)
